## Hướng dẫn Build và Nạp code

1.  Mở project bằng Keil uversion 5.
2.  Nhấn `Build` (F7).
3.  Kết nối mạch nạp ST-Link và nhấn `Run` (F8) để nạp chương trình.
4.  muốn chạy code phải tải thêm thư viện: STM32F10x_StdPeriph_Lib_V3.6.0 ---
